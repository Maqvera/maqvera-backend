# Common OpenAPI Fragments

Reserved for schema/parameter fragments genuinely shared across multiple API document versions (`../v1.yaml`, a future `../v2.yaml`, etc.) once a second version actually exists. Empty today — only `v1` exists (Enterprise API Version Strategy Standard, `docs/07-enterprise-standards/08-api-version-strategy.md`, has not registered a `v2` for any public API in this codebase yet), so there is nothing real to factor out. Not a placeholder for future work to fill blindly — populate it only when a genuine second version needs to reuse a fragment from `v1`.
